# マイアセット — iPhone アプリ化（PWA）手順

このフォルダの中身をインターネット上に置くと、iPhone のホーム画面から
アプリとして起動できるようになります。App Store も Mac も Apple の開発者登録も不要、費用は 0 円です。

## 入っているファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体。これ1つで動きます |
| `manifest.webmanifest` | アプリ名・アイコン・全画面表示の設定 |
| `sw.js` | オフラインでも起動できるようにする仕組み |
| `icon-192.png` / `icon-512.png` | ホーム画面・起動画面用アイコン |
| `apple-touch-icon.png` | iPhone のホーム画面アイコン |

**6つすべてが同じ場所に揃っている必要があります。**

---

## 手順1：インターネット上に置く（GitHub Pages）

無料です。GitHub のウェブサイト上だけで完結し、コマンド操作は必要ありません。

1. <https://github.com> でアカウントを作る（無料）
2. 右上の **＋** → **New repository**
3. **Repository name** に `shisan` と入力（好きな名前で可）
   - **Public** を選ぶ
   - **Create repository** を押す
4. 次の画面の **uploading an existing file** というリンクを押す
5. **この `pwa` フォルダを開き、中の6ファイルを選んでドラッグ＆ドロップ**する
   - ⚠️ フォルダごとではなく、**中身6つ**を入れてください。`index.html` がいちばん上の階層に来る必要があります
6. 下の **Commit changes** を押す
7. 上部タブの **Settings** → 左メニューの **Pages**
8. **Source** を `Deploy from a branch`、**Branch** を `main` / `/(root)` にして **Save**
9. 1〜2分待つと、同じ画面に URL が出ます

```
https://<あなたのユーザー名>.github.io/shisan/
```

この URL をメモしてください。

> **公開リポジトリで大丈夫？** 大丈夫です。公開されるのは**空のアプリのプログラムだけ**で、
> 入力した資産額は一切含まれません。金額はあなたの端末の中にしか保存されません。

### もっと簡単な方法（アカウント作成が面倒な場合）

<https://app.netlify.com/drop> にこのフォルダをドラッグするだけでも URL が発行されます。
ただし無料アカウントを作らないと数時間で消えるため、続けて使うなら GitHub Pages を推奨します。

## 手順2：iPhone のホーム画面に追加

1. iPhone の **Safari** で手順1の URL を開く（Chrome ではなく Safari）
2. 画面下の **共有ボタン**（□ から ↑ が出ているアイコン）をタップ
3. メニューを下にスクロールして **「ホーム画面に追加」**
4. 名前が「マイアセット」になっているのを確認して **「追加」**

ホーム画面にドーナツ＋¥のアイコンが並びます。
**以降はそのアイコンから起動してください。** URL バーもタブバーも出ない全画面表示になります。

### ⚠️ 最初に必ずやること

**データを入力する前にホーム画面に追加してください。**

iOS では、ホーム画面アプリと Safari のタブでデータの保存先が別々に扱われることがあります。
Safari のタブで先に入力すると、ホーム画面アプリ側からは空に見える場合があります。
もし先に入力してしまったら、Safari 側で「データ」タブから JSON を書き出し、
ホーム画面アプリ側で読み込めば移せます。

---

## データについて

- **保存先はその端末の中だけです。** サーバーには送られません
- **PC と iPhone のデータは自動同期しません。** 下の手順で手動同期します
- デスクトップの `資産管理.html` とこの PWA 版も、それぞれ別のデータを持ちます

### PC と iPhone を同期する

OneDrive や iCloud Drive を経由して、月に一度ほど手動で揃えます。

1. **書き出す側**（例: PC）でアプリを開き、「データ」タブ →「JSONで書き出す」
2. 書き出したファイルを **OneDrive / iCloud Drive のフォルダに保存**
3. **読み込む側**（例: iPhone）でアプリを開き、「データ」タブ → 読み込みのファイル選択
   - iOS のファイル選択画面から「ファイル」アプリ経由で OneDrive / iCloud Drive のファイルを直接選べます
4. **差分の確認画面**が出ます

確認画面には、両方の最終更新日時と、取り込まれる内容の内訳が出ます。

| ボタン | 動作 |
|---|---|
| **マージする** | 月ごとに新しいほうを採用。**今のデータは消えません**。通常はこちら |
| まるごと置き換える | 今のデータを全て捨ててファイルの内容にする。移行時など |
| キャンセル | 何もしない |

**マージの判定は月単位です。** 同じ月を両方の端末で編集した場合、あとから編集したほうが残ります。片方でしか触っていない月は、どちらの月もそのまま残ります。

一方で**月の削除は相手側に伝わりません**。片方で消した月がもう片方に残っていると、マージで戻ってきます。消すときは両方の端末で消してください。

事故を避けるには、**入力する端末を片方に決めて、もう片方は読み込むだけ**にするのが確実です。

### バックアップを習慣に

iPhone を機種変更したり、Safari の履歴とデータを消したりすると、保存内容も消えます。
**月に一度、入力したついでに「データ」タブから JSON を書き出す**ことをおすすめします。
書き出したファイルは iCloud Drive などに置いておけば安心です。

---

## アプリを更新するとき

`index.html` を書き換えたあとは、次の順で反映します。

1. `sw.js` の先頭にある
   ```js
   const CACHE = "myasset-v3";
   ```
   の番号を `shisan-v2` のように **1つ上げる**（これを忘れると古い画面が出続けます）
2. GitHub のリポジトリ画面で **Add file → Upload files** から、変えたファイルを上書きアップロード
3. iPhone 側でアプリをいったん完全に終了し（アプリスイッチャーで上にスワイプ）、開き直す

## うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| 全画面にならず Safari のバーが残る | `manifest.webmanifest` が読めていません。6ファイルが同じ階層にあるか、URL が `https://` で始まっているか確認 |
| アイコンが白紙や文字になる | `apple-touch-icon.png` が同じ階層にあるか確認。一度ホーム画面から削除して、追加し直す |
| 「ホーム画面に追加」が出てこない | Chrome など Safari 以外で開いています。Safari で開き直してください |
| 更新したのに古い画面が出る | 上の「アプリを更新するとき」の手順1（`CACHE` の番号上げ）を忘れています |
| 入力欄をタップすると画面が拡大する | 対策済みです。直らない場合は iOS の設定 → アクセシビリティ → ズーム を確認 |
| グラフが真っ白 | まだ残高が未入力です。「データ」タブの「サンプルデータを読み込む」で動作確認できます |
